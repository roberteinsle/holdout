# Holdout handbook

Holdout is a mobile-first web app that helps families build and keep an emergency food and water supply, and eat it before it expires. It is self-hosted: one installation serves one household.

> This handbook is the source of the project wiki. Edit the files in `handbuch/` and rebuild the wiki with `scripts/build-wiki.py`; never edit the wiki by hand.

## Pages

- [Installation](Installation.md): run Holdout with Docker and Coolify, environment variables, first start
- [Sign-in and security](Sign-in-and-security.md): passkeys, email links, authenticator app, recovery codes
- [Family and invitations](Family-and-invitations.md): owner and member roles, inviting and removing people
- [Design](Design.md): colours and contrast rules
- [Development](Development.md): local setup, tests, conventions, documentation workflow

## Status

Version 0.1 is in progress. Available so far: household setup, sign-in, family invitations. Stock tracking, barcode scanning, the dashboard and the shopping list follow.
